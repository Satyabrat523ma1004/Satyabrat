
# MATLAB Code for Line Sets in PG(3,2)

## Description

This repository contains MATLAB code for the computational search of line sets in the projective space PG(3,2).

The program constructs all points, lines, and planes of PG(3,2), computes the corresponding incidence matrices, and searches for a family of lines satisfying the prescribed incidence conditions.

## Incidence Conditions

- Every point is incident with either 3 or 4 lines of the selected family.
- Every plane contains either 3 or 4 lines of the selected family.

## Different Cardinalities

The provided MATLAB code searches for a line set of cardinality 16.

The same code can also be used to obtain line sets of cardinalities 17 and 19 by replacing the target size `16` with `17` or `19`, respectively, in the MATLAB program.

No change in the underlying construction or search algorithm is required.
